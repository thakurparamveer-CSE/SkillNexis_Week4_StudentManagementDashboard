# SkillNexis Week 4 - Student Management Dashboard

A front-end capstone project built with HTML, CSS and JavaScript.

## Features
- Add student records
- Edit student records
- Delete student records
- Save records in localStorage
- Styled student table
- Search by name, ID or email
- Filter by course and status
- Responsive layout
- Student statistics

## Files
- index.html
- style.css
- script.js

## How to run
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Assignment mapping
- CRUD operations: Add, Edit, Delete
- localStorage: browser storage
- DOM manipulation: dynamic table rendering
- Search bar: name, ID and email
- Filters: course and status
